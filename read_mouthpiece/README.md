# 已读，嘴替。

**按一下，保持体面；摇一下，说出心里话。**

一块能随身带走的人类状态牌：M5StickS3 上的绿色小人一本正经，摇一下就变成橙红色的内心吐槽。有人凑过来？按 B，立刻「热爱工作 / 情绪稳定」。内置打工人、社交、AI 三个梗包，共 18 张双面卡片，适合活动现场、合照和反转短视频。

这是**离线趣味台词作品**，所有状态、额度与 AI 活动都是预设文案，不检测心理，也不代表真实 AI 工作状态或真实剩余额度。不需要 Wi-Fi、账号或手机；默认静音，麦克风与扬声器关闭。

## 上手操作

开机直接显示「打工人 → 又加需求 → 收到，安排」。底部两组短提示每 4 秒交替出现，主文案不滚动。

| 操作 | 效果 |
| --- | --- |
| 短按 A | 当前梗包下一张卡，循环浏览，每次先显示体面话 |
| 明显来回摇一下 | 当前卡片体面话 / 内心话反转；背景与表情一起变化 |
| 按下 B | 立即恢复「热爱工作 / 情绪稳定」，绿色站直微笑，并解除锁定 |
| 恢复体面之后 | 摇动无效；短按 A 到下一张卡，继续玩 |
| 长按 A 约 0.8 秒 | 开启 / 关闭拍照锁定；小锁出现，停住小人和提示，忽略摇动与短按 A |
| 长按 B 约 1 秒 | 打工人 → 社交 → AI → 打工人；清除锁定及恢复画面，进入新包第一张体面话 |

长按只执行一次，松开不会再追加短按。B 在按下时就执行恢复，继续按住到阈值再切包，因此长按 B 的前一瞬会先看到恢复体面画面。A/B 同时操作时优先 B。

摇动识别需要一来一回的反向冲量，单次磕碰和单纯旋转不会按设计直接触发；一次反转后至少冷却 1.2 秒，并需要停稳至少 0.45 秒才重新待命。持续摇动只触发一次。按键后有 0.25 秒防误触保护。当前阈值已通过用户实机摇动与普通拿起/旋转检查；演示时自然来回摇一下后停住即可。

## 再编译与烧录

在上一级项目目录运行：

```bash
bash tools/build-mouthpiece.sh
```

脚本依次执行主机逻辑测试、字形覆盖与布局预览检查、真实 ESP32 编译，并保存日志、固件和 SHA-256。主机检查使用 `clang++` / `CXX`（含 AddressSanitizer、UndefinedBehaviorSanitizer）和 Python 3；不连接硬件。

已复用本机环境：Arduino CLI **1.5.1**、Espressif core **3.3.10-cn**、M5Unified **0.2.27**、M5GFX **0.2.34**。项目不更改全局配置。在其他电脑需先安装能支持 StickS3 的这两套 M5 库与 ESP32 core；首次使用后核对编译日志中的版本。

`sketch.yaml` 固定以下目标：

```text
esp32:esp32:esp32s3:FlashMode=qio,FlashSize=8M,PartitionScheme=default_8MB,PSRAM=opi,USBMode=hwcdc,CDCOnBoot=cdc,UploadMode=default,UploadSpeed=921600
```

| 配置 | 依据 |
| --- | --- |
| 芯片 | ESP32-S3-PICO-1-N8R8 |
| Flash / 分区 | 8MB QIO、80MHz，default_8MB（应用分区 3,342,336 字节） |
| PSRAM | 8MB Octal，`PSRAM=opi`、`memory_type=qio_opi` |
| USB | Hardware CDC/JTAG，启动启用 CDC，不等待串口连接 |
| 屏幕 | ST7789P3，物理 135×240，`setRotation(1)` 横屏 240×135 |
| 按钮 / 运动传感器 | A GPIO11、B GPIO12；BMI270，SDA47 / SCL48；由 M5Unified 管理 |

依据：[M5Stack 官方 StickS3 规格](https://docs.m5stack.com/en/core/StickS3)、[官方 Arduino 上传说明](https://docs.m5stack.com/en/arduino/m5sticks3/program)、[官方按钮示例](https://docs.m5stack.com/en/arduino/m5sticks3/button)。不要套用旧 M5StickC 的电源与引脚初始化。

连接支持数据传输的 USB-C 线后：

```bash
arduino-cli board list
# 把下面参数换为这一次实际检测并确认属于 M5StickS3 的端口：
bash tools/upload-mouthpiece.sh /dev/cu.usbmodem实际端口
```

上传脚本重新构建并保存上传日志，不沿用历史串口。如果自动进入下载模式失败：连接 USB，长按侧面的 **Reset 键约 2 秒**，看到内部绿灯闪烁后松开，再检测端口并上传。Reset 不是本作品的 B 键。上传完成仍停在下载模式时，短按 Reset 重启。若串口传输不稳定，可将 `sketch.yaml` 的 UploadSpeed 改为 115200 后重试。

烧录会替换这块板子上当前的程序；其他目录中的旧源码和固件仍保留。

## 加自己的梗

只需编辑 [`Cards.h`](Cards.h)。每个梗包是一个数组，新增一行即自动进入循环，不需要改按钮主流程：

```cpp
{"被临时加会", "好的，我来", "我先叹口气", Face::Smile, Face::Sweat, ""},
```

字段依次是：**场景、体面话、内心话、体面表情、内心表情、内心小字附注**。表情可选 `Smile`（微笑）、`Deadpan`（死鱼眼）、`Sweat`（汗）、`Collapse`（崩溃）、`Flat`（趴下）。常规体面表情请保持 `Smile`。

需要让句子在词组之间换行时，可以再加两个可选数字，分别指定体面话 / 内心话在第几个字符后优先断行，`0` 表示自动。例如「已开启多智能体」使用 `3`，会排成「已开启 / 多智能体」。不填写也可以正常显示，不需要改交互代码。

主文案建议 4–8 个汉字，最长两行；程序按 UTF-8 字符与实际字宽换行，不按字节切中文。修改后运行构建脚本，新增文字必须通过字形和区域宽度检查，再检查生成的预览。预览检查会拒绝装不进两行的文案；请缩短文字，不要用滚动长句破坏拍摄体验。中文使用 M5GFX 的 `efontCN_12` / `efontCN_16`，大字为 16px 字体整数放大两倍，保留清晰像素边缘；字库版权归其原作者，随 M5GFX 使用。

文件分工：`Cards.h` 放文案；`Controller.h` 管按键和状态；`ShakeDetector.h` 管运动识别；`Ui.h` 绘制画面；`.ino` 管硬件与非阻塞调度。屏幕先在 16 位画布中绘制，再一次推送；反转反馈约 240ms，主文案立即呈现目标内容，稳定后仅低频更新小人，锁定后不重绘。没有后台、手机页、在线库和真实 AI 请求。

## 15 秒短视频脚本

| 时间 | 台词 / 动作 | 屏幕 |
| --- | --- | --- |
| 0–3 秒 | 同事：「这个需求很简单吧？」镜头推近手中的牌 | 绿色「收到，安排」 |
| 3–6 秒 | 你微笑点头，等同事转身，来回摇一下 | 橙红「你来，你来」和崩溃小人 |
| 6–9 秒 | 停住给镜头看；同事突然凑过来：「你说什么？」 | 内心画面停留 |
| 9–12 秒 | 迅速按 B，自己也同时站直、露出标准微笑 | 绿色「热爱工作 / 情绪稳定」 |
| 12–15 秒 | 镜头定格：「已读，嘴替。按一下保持体面，摇一下说心里话。」 | 恢复画面保持不动 |

一分钟现场展示：前 15 秒演上面这段；接着按 A，再摇出一条新梗；长 A 锁住举起来让观众拍照，摇和短 A 都不动；最后按 B 再次「情绪稳定」，长 B 换社交 / AI 梗包让观众挑台词。每次摇完停住，笑点留给屏幕和你的表情。
